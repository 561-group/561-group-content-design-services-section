# Translation

Translate the [slogan](../../../../glossary/terms/slogan-as-argument.md) and the [GROUP wordmark](../elements/group-wordmark.md) into any language a 561 contributor reads or speaks.
The morphism preserves word order, names the translator, and constrains which lockups the translation may appear in.

## Slogan translation

1. **Permitted languages.** Any language a 561 contributor reads or speaks.
2. **Word order.** Preserve `Land · Water · Language · Culture` order even when the target-language syntax would prefer otherwise.
  The order is load-bearing — see [slogan-as-argument](../../../../glossary/terms/slogan-as-argument.md).
3. **When syntax cannot bear it.** Set the translation as four separate sentences.
  Do not collapse two words into a phrase to honor target syntax.
4. **Set rules.** The translated slogan follows the same [slogan-setting](slogan-setting.md) geometry as the English slogan: stacked variant for masthead use, inline for colophons, contracted for sticker scale.
5. **Colophon credit.** The translator's name and the language pair appear in the [colophon](../elements/colophon-stamp.md) (see § 11.x).

## Wordmark translation

The [GROUP wordmark](../elements/group-wordmark.md) may be translated in the inline (B) and foot (C) lockups.
The vertical (A) lockup retains the English wordmark to keep the geometric block consistent across translated artifacts.

Bible-recognized translated wordmarks at the same metrics:

| Code | Wordmark | Language |
|------|----------|----------|
| es   | GRUPO    | Spanish  |
| ht   | GWOUP    | Haitian Creole |
| fr   | GROUPE   | French   |

New translated wordmarks earn an entry in this table after the [translation morphism](translation.md) has been run twice on artifacts the council has approved.

## Mark itself

The [primary mark](../elements/five-six-one-mark.md) does not translate — *561* is a numeral and reads in any language.
The [contracted mark](../elements/contracted-mark.md) and the [stamp mark](../elements/stamp-mark.md) likewise do not translate.

## Procedure

1. Select the language.
  Confirm a 561 contributor reads or speaks it.
2. Translate the slogan word-by-word.
  Preserve order.
  Where target syntax breaks, set as four separate sentences.
3. Translate the wordmark, if used in the inline or foot lockup.
  Use the bible-recognized translation if the language is in the table above.
4. Set the translated slogan via [slogan-setting](slogan-setting.md), the translated wordmark via [lockup-selection](lockup-selection.md).
5. Add to the [colophon](../elements/colophon-stamp.md): translator's name (full), language pair (`en→es`), date.

## Forbidden

- Translation of the [primary mark](../elements/five-six-one-mark.md).
  The numeral is the mark.
- Translation that collapses or reorders the slogan words.
- Translation by machine without a human translator's review and credit.
- Anonymous translations.
  The translator is named, full, in the colophon.

## Check

The translated slogan, set in stacked variant, reads as four declarative words in a sequence of dependencies — the same argument as the English slogan, just carried in a different language.
If the translation reads as a noun phrase or a slogan in the marketing sense ("water flows through language to culture"), the translation has failed; reset to four-separate-sentences and re-translate.
